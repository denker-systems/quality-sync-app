## Implementation

### useAuth Hook

The `useAuth` hook provides authentication state and methods:

```typescript
const {
  user,           // Current user object
  session,        // Current session
  loading,        // Loading state
  signIn,         // Sign in method
  signOut,        // Sign out method
} = useAuth();
```

**Location:** `src/hooks/useAuth.ts`

#### Sign In

```typescript
const signIn = async (email: string, password: string) => {
  const { data, error } = await supabase.auth.signInWithPassword({
    email,
    password,
  });
  
  if (error) throw error;
  return data;
};
```

#### Sign Out

```typescript
const signOut = async () => {
  const { error } = await supabase.auth.signOut();
  if (error) throw error;
};
```

#### Session Listener

```typescript
useEffect(() => {
  // Listen for auth state changes
  const { data: { subscription } } = supabase.auth.onAuthStateChange(
    (_event, session) => {
      setSession(session);
      setUser(session?.user ?? null);
    }
  );

  return () => subscription.unsubscribe();
}, []);
```

### Login Screen

**Location:** `src/screens/auth/LoginScreen.tsx`

```typescript
export default function LoginScreen() {
  const { signIn } = useAuth();
  const [loading, setLoading] = useState(false);

  const handleLogin = async (email: string, password: string) => {
    setLoading(true);
    try {
      await signIn(email, password);
      // Navigation handled by AppNavigator
    } catch (error) {
      Alert.alert('Error', error.message);
    } finally {
      setLoading(false);
    }
  };

  return (
    <View>
      {/* Login form */}
    </View>
  );
}
```

## PKCE Flow

PKCE (Proof Key for Code Exchange) is used for secure authentication in mobile apps.

### Configuration

**Location:** `src/config/supabase.ts`

```typescript
const supabase = createClient(supabaseUrl, supabaseAnonKey, {
  auth: {
    storage: AsyncStorage,
    autoRefreshToken: true,
    persistSession: true,
    detectSessionInUrl: false,
  },
});
```

### How PKCE Works

1. **Code Verifier:** Random string generated by client
2. **Code Challenge:** SHA-256 hash of code verifier
3. **Authorization:** Client sends code challenge
4. **Token Exchange:** Client proves ownership with code verifier

**Benefits:**
- Prevents authorization code interception
- No client secret needed
- Secure for mobile apps

## Session Management

### Session Storage

Sessions are stored in AsyncStorage:

```typescript
import AsyncStorage from '@react-native-async-storage/async-storage';

const supabase = createClient(url, key, {
  auth: {
    storage: AsyncStorage,
    persistSession: true,
  },
});
```

### Session Persistence

Sessions persist across app restarts:

1. User logs in
2. Session stored in AsyncStorage
3. App closes
4. App reopens
5. Session automatically restored

### Token Refresh

Tokens are automatically refreshed before expiry:

```typescript
auth: {
  autoRefreshToken: true,  // Enable auto-refresh
}
```

### Session Expiry

Default session expiry: **7 days**

After expiry:
- User is automatically logged out
- Redirected to login screen
- Must re-authenticate

## Security Features

### Password Requirements

Enforced by Supabase:
- Minimum 6 characters
- No maximum length
- No complexity requirements (configurable)

### Rate Limiting

Supabase provides built-in rate limiting:
- Max login attempts per IP
- Temporary lockout after failed attempts
- Email verification for suspicious activity

### Secure Storage

- **AsyncStorage:** Encrypted on iOS, secure on Android
- **No plain text:** Passwords never stored locally
- **Token security:** Access tokens stored securely

## Error Handling

### Common Errors

```typescript
try {
  await signIn(email, password);
} catch (error) {
  if (error.message.includes('Invalid login credentials')) {
    // Wrong email or password
  } else if (error.message.includes('Email not confirmed')) {
    // Email verification required
  } else if (error.message.includes('Too many requests')) {
    // Rate limit exceeded
  } else {
    // Generic error
  }
}
```

### User Feedback

```typescript
const handleError = (error: Error) => {
  let message = 'An error occurred';
  
  if (error.message.includes('Invalid login credentials')) {
    message = 'Invalid email or password';
  } else if (error.message.includes('Email not confirmed')) {
    message = 'Please verify your email';
  }
  
  Alert.alert('Login Failed', message);
};
```

## Navigation Integration

### AppNavigator

**Location:** `src/navigation/AppNavigator.tsx`

```typescript
export default function AppNavigator() {
  const { user, loading } = useAuth();

  if (loading) {
    return <LoadingScreen />;
  }

  return (
    <NavigationContainer>
      {user ? <MainStack /> : <AuthStack />}
    </NavigationContainer>
  );
}
```

### Conditional Rendering

- **No user:** Show AuthStack (LoginScreen)
- **User exists:** Show MainStack (ProfileScreen, etc.)
- **Loading:** Show loading indicator

## Troubleshooting

### Session Not Persisting

**Problem:** User logged out after app restart

**Solutions:**
1. Check AsyncStorage permissions
2. Verify `persistSession: true` in config
3. Clear app data and try again

### Login Fails Silently

**Problem:** No error message shown

**Solutions:**
1. Check network connection
2. Verify Supabase URL and anon key
3. Check console for errors
4. Verify user exists in Supabase dashboard

### Token Refresh Fails

**Problem:** User logged out unexpectedly

**Solutions:**
1. Check `autoRefreshToken: true` in config
2. Verify network connectivity
3. Check Supabase project status

## Best Practices

1. **Never store passwords** - Only store session tokens
2. **Handle errors gracefully** - Show user-friendly messages
3. **Validate input** - Check email format before submission
4. **Secure storage** - Use AsyncStorage for tokens
5. **Auto-refresh tokens** - Enable automatic refresh
6. **Clear sessions on logout** - Remove all stored data
